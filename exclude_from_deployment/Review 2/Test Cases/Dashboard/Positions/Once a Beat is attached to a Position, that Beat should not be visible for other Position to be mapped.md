### Description
Create an `L1 Postion` and few `Beats`. Map one of the created `beat` to the `L1 Position` we just created. PFB. example: `Aminjikarai GT 1` is mapped to `SouthChennaiGT` position.
![[Pasted image 20260605224315.png]]

Next, Navigate to `+ New Position`. PFB.
![[Pasted image 20260605230430.png]]
Aminjikarai GT 1 is showing as default beat that can be saved. 
As a fundamental principle, any `beat` that is already mapped to an `existing position` should not be available to be mapped to a `new position` for that matter, any `other position` . Logic is `one beat` can be mapped to one and only one `position`. However, a `position` can contain multiple `beats`
